# ValutaTrade Hub

Консольное приложение для симуляции торговли валютами.

Позволяет регистрироваться, входить в систему, просматривать портфель,
покупать и продавать валюты, получать курсы.

## Требования

- Python 3.12 или новее.
- uv.

## Установка и запуск

Склонируйте репозиторий и перейдите в корень проекта.

Установите зависимости:

```text
uv sync
```

Запустите приложение:

```text
uv run valutatrade
```

После запуска вводите команды в приглашении «Введите команду».

Для завершения работы:

```text
exit
```

Запускайте приложение из корня проекта: здесь читается `pyproject.toml`, а пути к данным и логам
считаются относительно текущей рабочей папки.

## Поддерживаемые валюты

| Код   | Валюта             |
| ----- | ------------------ |
| USD   | Доллар США         |
| EUR   | Евро               |
| RUB   | Российский рубль   |
| BTC   | Bitcoin            |
| ETH   | Ethereum           |

На текущем этапе используются фиксированные учебные курсы.
Подключение к реальному источнику курсов не реализовано.

## Команды

Порядок аргументов в командах должен соответствовать примерам.

### Регистрация

```text
register --username alice --password 1234
```

Имя должно быть непустым и уникальным. Пароль не короче четырёх символов.

При регистрации создаётся пользователь и пустой портфель.
Пароль сохраняется в виде SHA-256-хеша с индивидуальной солью.

### Вход

```text
login --username alice --password 1234
```

После успешного входа приложение запоминает текущего пользователя
до завершения работы. При следующем запуске нужно войти заново.

### Просмотр портфеля

```text
show-portfolio
```

Базовая валюта по умолчанию задаётся настройкой `default_base_currency`.
В приведённой ниже конфигурации это USD.

Для выбора другой базовой валюты:

```text
show-portfolio --base EUR
```

Выводятся балансы кошельков, их стоимость в базовой валюте
и общая стоимость портфеля.

Команда доступна после входа.

### Покупка валюты

```text
buy --currency EUR --amount 10
```

`amount` - количество покупаемой валюты.

Стоимость покупки списывается с USD-кошелька.
Кошелёк покупаемой валюты создаётся автоматически, если его ещё нет.

Для покупки необходимо войти в систему и иметь достаточно USD.
Покупка USD за USD запрещена.

### Продажа валюты

```text
sell --currency EUR --amount 5
```

`amount` - количество продаваемой валюты.

Валюта списывается с соответствующего кошелька,
выручка начисляется на USD-кошелёк.
Если USD-кошелька нет, он создаётся автоматически.

Для продажи необходимо войти в систему и иметь достаточно
продаваемой валюты. Продажа USD за USD запрещена.

### Получение курса

```text
get-rate --from USD --to BTC
```

Выводятся прямой курс, время его обновления и обратный курс.
Вход в систему не требуется.

Курсы сохраняются в кеше. Срок свежести задаётся `rates_ttl_seconds`
(в приведённой конфигурации - 300 секунд). Свежие записи используются
повторно, остальные обновляются через учебную заглушку.

## Подготовка баланса для проверки

После регистрации портфель пустой. Команда пополнения USD
в текущей версии отсутствует.

Для проверки сделок:

1. Зарегистрируйте тестового пользователя и запомните его ID.
2. Завершите приложение.
3. Откройте файл из настройки `portfolios_path` (в примере - `data/portfolios.json`).
4. Найдите объект портфеля с этим `user_id`.
5. Добавьте в его пустой словарь `wallets` USD-кошелёк.

Например, для пользователя с ID `3` запись должна выглядеть так:

```json
{
    "user_id": 3,
    "wallets": {
        "USD": {
            "balance": 100.0
        }
    }
}
```

Используйте ID своего пользователя. Это один элемент списка
в `portfolios.json`: сохраните внешние квадратные скобки файла
и портфели остальных пользователей.

Запустите приложение, войдите под тестовым пользователем и выполните:

```text
show-portfolio
buy --currency EUR --amount 10
show-portfolio
sell --currency EUR --amount 5
show-portfolio
```

## Настройки

Настройки задаются в секции `[tool.valutatrade]` файла `pyproject.toml`:

| Ключ                    | Назначение                                                  | Значение в конфигурации |
| ----------------------- | ----------------------------------------------------------- | ----------------------- |
| `users_path`            | Файл пользователей                                          | `data/users.json`       |
| `portfolios_path`       | Файл портфелей                                              | `data/portfolios.json`  |
| `rates_path`            | Кеш курсов                                                  | `data/rates.json`       |
| `rates_ttl_seconds`     | Срок свежести курса в секундах                              | `300`                   |
| `default_base_currency` | База команды `show-portfolio` без `--base`                  | `USD`                   |
| `log_path`              | Файл логов                                                  | `logs/actions.log`      |
| `log_level`             | Уровень логирования                                         | `INFO`                  |
| `log_format`            | Обозначение выбранного формата; переключение не реализовано | `text`                  |

Эти значения задаются в конфигурации проекта; загрузчик не подставляет их автоматически при отсутствии ключей. `SettingsLoader` загружает
настройки один раз; после изменения файла перезапустите приложение.
`DatabaseManager` получает пути из настроек и выполняет чтение и сохранение JSON.
Оба класса реализованы как Singleton: повторное создание возвращает тот же экземпляр.
Настройка базовой валюты влияет на отображение портфеля; сделки выполняются через USD.

## Валюты и ошибки

Валюты представлены абстрактным классом `Currency` и наследниками
`FiatCurrency` и `CryptoCurrency`. Реестр `CURRENCIES` и функция `get_currency()`
находятся в `core/currencies.py`. Коды при поиске приводятся к верхнему регистру.

В `core/exceptions.py` определены:

- `InsufficientFundsError` — недостаточно средств; сообщение содержит доступную и требуемую суммы.
- `CurrencyNotFoundError` — неизвестная валюта; CLI дополнительно показывает поддерживаемые коды.
- `ApiRequestError` — сбой источника курсов; CLI предлагает повторить попытку позже или проверить сеть.

Источник пока является учебной заглушкой и не выполняет сетевых запросов.

## Логирование

При запуске CLI настраивается запись в `logs/actions.log`.
Папка создаётся автоматически. По умолчанию используется уровень `INFO`;
для отладки можно указать `DEBUG`.

Реализован текстовый формат. Значение `log_format = "text"` обозначает
выбранный формат в конфигурации, но сейчас не используется для переключения
форматирования. Изменение этого значения не включает JSON-формат.

Декоратор `@log_action(verbose=True)` подключён к покупке и продаже.
Записи содержат время, действие, пользователя, валюту, количество, базовую валюту
и результат. При успехе добавляется курс, а при `verbose=True` — баланс до и после.
При ошибке записываются её тип и сообщение; исключение передаётся дальше в CLI.

Пример записи:

```text
INFO 2026-10-25T16:38:22 BUY user='alice' currency='EUR' amount=1.0 rate=1.1 base='USD' result=OK balance_before=10.0 balance_after=11.0
```

Лимит файла — 1 000 000 байт. Ротация сохраняет до трёх резервных файлов:
`actions.log.1`, `actions.log.2`, `actions.log.3`.
Логи исключены из Git через `logs/` в `.gitignore`.

## Хранение данных

При указанных выше настройках файлы создаются в папке `data/`:

- `users.json` — пользователи, хеши паролей, соли и даты регистрации.
- `portfolios.json` — портфели и балансы кошельков.
- `rates.json` — кеш курсов и время их обновления.

Пользователи и портфели сохраняются между запусками приложения.

## Структура проекта

```text
valutatrade_hub/
├── logging_config.py  # формат, уровень и ротация логов
├── decorators.py      # декоратор log_action
├── core/
│   ├── currencies.py  # иерархия и реестр валют
│   ├── exceptions.py  # пользовательские исключения
│   ├── models.py      # User, Wallet, Portfolio
│   ├── utils.py       # JSON, преобразования, валидаторы, расчёт курсов
│   └── usecases.py    # регистрация, вход, сделки, сводка и кеш
├── infra/
│   ├── settings.py    # Singleton SettingsLoader
│   └── database.py    # Singleton DatabaseManager
└── cli/
    └── interface.py   # ввод команд и вывод результатов
```
